## 1. What Pedalshield is

Privacy-first **bike-to-earn iOS app on Zcash** — *"Ride private. Earn shielded."*
It pays riders **real shielded ZEC** for verified rides, with the reward
**pegged to carbon value: $0.006/mile** (the worth of 1 lb of CO₂ kept out of
the air by biking instead of driving). Built for the **ZecHub Hackathon 3.0**
(Games track, **deadline July 15, 2026**).

Owner: **Samuel B. Newman, CEO, Intelligrip Industries** (intelligripindustries@gmail.com).

Core principle that constrains every decision: **non-custodial + honest**.
Pedalshield never holds user funds or keys, and claims must stay truthful
(no overstating what the deployed system does).

## 3. Architecture in one screen

- **Mobile:** bottom tabs — **Home, Ride, Leaders, Market, Privacy**. Ride
  tracking uses `expo-location` + `expo-sensors` with on-device verification
  (real-vs-spoof). Rewards display, wallet connect (UA/`u1…`), privacy reveal
  sheet (Strava-leaky vs Pedalshield-minimal payload — strongest demo artifact).
  The project ships **hand-written type shims** (`mobile/src/types/react-native-shim.d.ts`)
  so `tsc --noEmit` runs without native deps installed; real packages shadow the
  shim at EAS build time.
- **Backend:** hand-rolled, **SDK-free Orchard spend pipeline** in Rust (tree
  seeding from `GetTreeState`, scan-to-tip, note selection, v5 builder,
  prove/sign/broadcast). NU6.2 (branch `0x5437f330`). Dual-scope scanner
  (External + Internal) — fixed an earlier "missing 1.1 ZEC" change-note bug.
  **Accrual mode** (`accrual.rs`): rides accrue off-chain and settle on-chain at
  a floor (0.01 ZEC) so fees aren't >100% of dust payouts. Verification is
  unchanged by accrual — it only batches settlement.
- **Carbon peg:** `793 zat/km` at ZEC ≈ $470. Re-peg via `deploy/repeg_carbon_rate.sh`
  (and now the new oracle). Reward math in `mobile/src/lib/config.ts`
  (`DEFAULT_ZAT_PER_KM = 793`) and `types.rs::compute_reward_zatoshi`.
- **Treasury pool UA:** `u19r0gg89utgp9kcqtdasfyfc6nds5sc6tgzny2sgvrsuyw3z97kkg45h87gufsamfhmyxfykg6amlk3lp0ynlc9wgxx60v9gdsuap0zk9`

## 6. Launch critical path (App Store)

1. **THE gate — App Review guideline 3.1.5(v):** crypto apps "may not offer
   currency for completing tasks." Pedalshield's earn-ZEC-for-rides core lives in
   this blast radius. Mitigation: position as a **fitness/activity reward for
   verified physical exercise** (Sweatcoin-style precedent exists), ZEC is **paid
   out, never sold as investment**. Lead listing + reviewer notes with the
   fitness/carbon framing, not "earn money." **Apple Developer account must be an
   Organization enrollment** (wallet rule). Marketplace must stay **physical
   goods / real-world services** (not IAP-eligible digital content → avoids 3.1.1).
2. **Map = native dependency** → requires a full **EAS Build + new TestFlight +
   App Store submission** (not an OTA update). Run **`npx expo install
   react-native-maps`** first to pin the SDK-56-correct version; bump
   `app.json` version/build number.
3. **Confirm the live OSM tag** for Spend Nearby on a real device — the sandbox
   couldn't reach Overpass, so the tag set (`currency:ZEC`, `payment:zcash` in
   `spend/geo.ts::ZEC_OSM_TAGS`) is a configurable best-guess until verified.
4. **On-device mining is banned by Apple, but Pedalshield mines server-side** —
   a non-issue for review. Do **not** mention in-app mining in the listing.

## 7. Mining + capital (the funding model)

- ZEC mining is **ASIC-only** in 2026 (Antminer **Z15 Pro**: ~840 kSol/s,
  ~2,700 W, ~$4,100). User is evaluating a **miner + 12-month hosting bundle ~$8,460**.
- Conservative yield **~$20/day ≈ $7,300/yr/machine**. Carbon base rate makes a
  rider cost only **~$11/yr** (≈5 mi/day), so **one machine funds ~500–700 riders**.
- **Capital tiers:** ~1,000 riders → 2 machines (~$17k); ~10,000 → ~17 (~$145k);
  ~100,000 → ~170 (~$1.4M). Size at a **1.5–2× coverage ratio** for ZEC price risk.
- **"Internally host the miners"** (user intent): colocation (~$0.06/kWh) vs.
  in-house. Either way, **point miner payouts at the treasury pool UA** with a
  `mining-split` / `MINER:<id>` memo; `pool.rs` credits inflows via the
  viewing-key scanner. This is the *"mining funds riding"* loop.
- **Investor recoup:** (A) equity / SAFE backed by the rigs as a hard asset
  (exit upside), and/or (B) equipment **revenue-share** (~14-month payback from
  ZEC output, hardware as collateral). **Securities counsel before any
  instrument.** Keep rider rewards **completely separate** from any investment.
- **Market context:** ZEC is mid-crash from the **Orchard pool bug disclosed
  2026-06-05** (~$230–440 range). Mining yield (in ZEC) swings with price while
  payouts are USD-fixed — hence the coverage ratio.

## 9. Hard rules to preserve

- **Non-custodial:** Pedalshield never holds funds or keys (rider, merchant, or
  marketplace). Don't add a flow that routes funds through the platform.
- **Honest claims:** `/treasury/info` and all messaging must reflect what the
  deployed system actually does. No overstatement.
- **Rewards ≠ investment:** the earned ZEC is payment for verified activity, kept
  separate from any investor instrument (legal + brand + Apple).
- **Rust builds on the droplet**, not in this sandbox. Don't claim Rust changes
  are verified until `cargo test` runs there.
